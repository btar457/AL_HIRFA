# 🏛️ AL-HIRFA | منصة الحرفة لتوثيق وتداول التراث العراقي

<p align="center">
  <b>منصة برمجية سينمائية متكاملة لإحياء وصيانة تراث بلاد الرافدين بأيدٍ حرفية أصيلة، مدعومة بالذكاء الاصطناعي لضبط الجودة ومكافحة الغش التجاري.</b>
</p>

---

## 🌟 رؤية المشروع (Project Vision)
تهدف منصة **الحرفة** إلى ربط الحرفيين العراقيين (في النحاسيات، سجاد وتطريز الرافدين، النحت والخط العربي، والأعمال التراثية) بالأسواق المحلية والعالمية، مع الحفاظ على الهوية الأصيلة للمنتجات الفنية ومنع تداول السلع المقلدة أو المستوردة عبر دمج نظام فحص ذكي متطور.

## 🏗️ الهيكل البرمجي والأنظمة المتكاملة (System Architecture)
يحتوي التطبيق المبني بإطار العمل **Flutter** على أربعة أنظمة تشغيلية مترابطة تنسجم ديناميكياً معاً:

1. **🛍️ لوحة المشتري (Buyer Journey):** تصفح المعرض التراثي، التنقل بين التصنيفات، واقتناء التحف عبر بوابات دفع آمنة وموثقة.
2. **🔨 لوحة التحكم للحرفي (Artisan Dashboard):** إدارة المخزون، ورفع المنتجات الجديدة، مع دمج **مستشار الأصالة الذكي**.
3. **🚚 النظام اللوجستي (Logistics Hub):** تتبع الشحنات الحساسة بين المحافظات وتوثيق حالة التسليم بالصور لضمان سلامة القطع الفنية.
4. **🛡️ بوابة التحكم العليا للمؤسس (Founder Portal):** مراقبة الامتثال، إدارة العمولات، ومراجعة المنتجات لضمان أعلى معايير الجودة.

---

## 🧠 دمج الذكاء الاصطناعي (Google Gemini AI Integration)
تم تزويد المنصة بنظام تدقيق تلقائي قائم على نموذج **Gemini 1.5 Flash** عبر **Google AI Studio**، حيث يعمل المحرك على:
* تحليل المكونات والمواد الإنشائية للمنتجات المرفوعة فوراً.
* إصدار قرارات فورية بـ (القبول / الرفض / التعليق للمراجعة الميدانية) بصيغة برمجية موحدة (JSON).
* كشف البضائع الدخيلة والمستوردة لحماية الحرفيين المحليين.

---

## 🔒 معايير الأمان وحماية البيانات (Security & Compliance)
تم بناء التطبيق وفقاً لأعلى معايير الحماية البرمجية:
* **التشفير البيئي:** يتم استدعاء مفاتيح الـ API الخاصة بالذكاء الاصطناعي بشكل مشفر وديناميكي عبر البيئة التشغيلية المستقلة (`--dart-define=GEMINI_API_KEY`) لحماية البيانات ومنع تسريب الثغرات الأمنية على المستودعات العامة.

## 🚀 التشغيل وبدء العمل (How to Run)

لتشغيل المشروع ومعاينته محلياً، تأكد من وجود بيئة عمل Flutter مثبتة، ثم نفذ الأوامر التالية:

```bash
# استدعاء الحزم والمكتبات
flutter pub get

# تشغيل التطبيق مع تمرير مفتاح الذكاء الاصطناعي كمتغير بيئي آمن
flutter run --dart-define=GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
